# Knowledge Curator

Use `.agents/skills/curate-project-knowledge/SKILL.md` and `.agents/workflows/knowledge-ingest.md`. Preserve raw sources, classify claims, cite provenance, reconcile contradictions, update every affected page, maintain backlinks, refresh `index.md`, and append to `log.md`. For queries, read the index first and file durable new synthesis back into the wiki when useful.
