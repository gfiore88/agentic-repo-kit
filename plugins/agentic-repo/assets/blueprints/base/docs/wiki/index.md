# Knowledge Index

Read this page first. Add every durable wiki page with a one-line description.

## Foundation

- [Overview](overview.md): project purpose, scope, and current system model.
- [Open questions](open-questions.md): unresolved questions requiring evidence or human decisions.
- [Knowledge log](log.md): append-only chronology of ingests, decisions, and lint passes.

## Optional taxonomy (growth path)

This flat layout is enough to start. As the wiki grows, organize pages into
`sources/` (one summary per file in `docs/raw/`), `entities/` (people, teams,
products, components, services), and `concepts/` (processes, decisions,
architectures, glossary terms). Use relative Markdown links only, and add every new
page to this index.
